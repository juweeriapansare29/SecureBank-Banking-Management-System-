JAVA OOP PROJECT

SecureBank

One project bundle for the responsive website, Android app, Java Servlet backend, Hibernate and MySQL schema.

Preview the interface now

Open the responsive SecureBank website in your browser. This is a demo UI and uses sample data in the browser.

Run the full web project

  1. Install JDK 17, Maven, MySQL, and a Jakarta Servlet 6-compatible server (for example Tomcat 10.1).
  2. Create the database using java-backend/database/schema.sql.
  3. Configure the database connection using the environment variables documented in java-backend/README.md.
  4. Build the WAR from java-backend with mvn clean package, then deploy target/securebank.war to your servlet container.
  5. Open http://localhost:8080/securebank/ to see the website served by the Java project. /api/accounts is the sample API endpoint.

Run the Android app

Open the android folder in Android Studio, sync Gradle, then run on an emulator or phone. It contains the same responsive UI inside a WebView.

Important scope

Login, registration, transfers, beneficiaries, KYC and admin actions in the UI are currently demo interactions. The Java accounts endpoint is a starter sample; the UI has not yet been connected to authenticated server APIs for every feature. No real money moves. Do not use real banking credentials or personal data.
